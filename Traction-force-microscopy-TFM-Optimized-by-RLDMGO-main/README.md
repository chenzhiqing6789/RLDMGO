This repository implements the RLSBO (Reinforcement Learning Satin Bowerbird Optimizer) algorithm to automatically search for the optimal deep learning architecture.
Instead of manually tuning hyperparameters, this code uses RLSBO to efficiently find the best network structure for your specific task.
The dataset is NOT included in this repository.
Ensure MATLAB is installed with the Deep Learning Toolbox.
Download and place the dataset in the folder.
Run the main script in MATLAB. RLSBOMain3
