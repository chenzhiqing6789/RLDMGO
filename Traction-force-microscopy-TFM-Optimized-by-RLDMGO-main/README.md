This repository implements the RLDMGO algorithm to automatically search for the optimal deep learning architecture.
Instead of manually tuning hyperparameters, this code uses RLDMGO to efficiently find the best network structure for specific task.
The dataset is NOT included in this repository.
Ensure MATLAB is installed with the Deep Learning Toolbox.
Download and place the dataset in the folder.
Run the main script in MATLAB. RLDMGOMain3
