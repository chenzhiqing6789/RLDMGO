This repository implements the RLDMGO algorithm to automatically search for the optimal deep learning architecture.
Instead of manually tuning hyperparameters, this code uses RLDMGO to efficiently find the best network structure for specific task.
The dataset is NOT included in this repository.Specifically, the implementation and dataset for the CEC2017 benchmark suite can be accessed via the official repository (https://github.com/P-N-Suganthan/CEC2017-BoundContrained). The public feature selection datasets, along with the complete source code and implementation instructions for the proposed RLDMGO algorithm, are available at the GitHub repository (https://github.com/chenzhiqing6789/RLDMGO). Additionally, the traction force microscopy (TFM) data used for evaluation can be accessed via the Box repository (https://cmu.box.com/s/n34hbfopwa3r6rftvtfn4ckc403hk43d). 
Ensure MATLAB is installed with the Deep Learning Toolbox.
Download and place the dataset in the folder.
